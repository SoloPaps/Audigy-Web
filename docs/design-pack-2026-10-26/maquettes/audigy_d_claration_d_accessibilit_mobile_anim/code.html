3. Choix techniques d'accessibilité

L’architecture d’Audigy a été conçue pour éviter toute surcouche artificielle. Nous valorisons les standards ouverts du web et minimisons les dépendances externes lourdes.

code

HTML5 Sémantique natif

Hiérarchie stricte des titres, balises sémantiques (main, nav, article), boutons natifs et formulaires explicitement liés.

text_fields

Atkinson Hyperlegible & Outfit

Polices auto-hébergées optimisées pour la distinction sans ambiguïté des caractères (notamment zéro, O, 1, I, l).

record_voice_over

Retour dynamique ARIA

Régions aria-live dédiées aux alertes d’audit, retours d’erreurs immédiats et étiquetage explicite des graphes.

tab

Navigation tabulaire libre

Ordre séquentiel cohérent et anneau de surbrillance orange contrasté 2px (#C2410C) sur tous les états focalisables.
