Tu es un ingénieur web expert en performance, sécurité et accessibilité.
Corrige les 4 anomalies identifiées lors de l'audit technique d'Audigy :

1. [SÉCURITÉ] Activer l'en-tête HSTS :
   - Définir `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload` dans la config serveur/CDN (netlify.toml, vercel.json ou nginx).

2. [SÉCURITÉ] Configurer la CSP (Content-Security-Policy) :
   - Restreindre default-src 'self' et interdire inline-scripts non signés.

3. [PERFORMANCE] Convertir les images bitmap en AVIF / WebP :
   - Remplacer le fichier hero de 2.4 Mo par une version compressée AVIF < 200 Ko.
