Méthode recommandée : Balise HTML

bolt Instantané

Insérez cet élément unique dans la section <head> de votre page d'accueil, avant le premier bloc <body>.

Ne modifiez pas la clé secrète générée. Elle garantit l'intégrité de vos rapports d'observabilité et prévient toute prise de contrôle concurrente.

Preuve par fichier statique

Créez un fichier texte nommé audigy-verification.txt à la racine publique de votre domaine à l'URL suivante :

https://acme-analytics.fr/audigy-verification.txt

Contenu requis dans le fichier :

audigy_site_verify_9b7c82a1f4

Preuve par enregistrement DNS TXT

Ajoutez un enregistrement DNS de type TXT auprès de votre registrar ou hébergeur DNS sur l'hôte @ (ou nom racine).

audigy-site-verification=audigy_site_verify_9b7c82a1f4
