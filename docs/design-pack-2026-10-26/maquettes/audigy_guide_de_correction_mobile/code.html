Comment corriger : En-tête HSTS

Le protocole HTTP Strict Transport Security contraint les navigateurs à utiliser systématiquement une connexion chiffrée SSL/TLS.

schedule
Temps estimé 15 min
admin_panel_settings
Rôle suggéré Hébergeur / SysAdmin
4 hébergeurs
1

Localiser le fichier source

Localisez votre fichier de configuration d'en-têtes (netlify.toml ou vercel.json) situé à la racine du projet.

2

Ajouter la directive HSTS

Collez la section suivante dans le bloc des en-têtes HTTP de votre hébergement :

netlify.toml 
[[headers]]
  for = "/*"
  [headers.values]
    Strict-Transport-Security = "max-age=63072000; includeSubDomains; preload"
warning

Validation préalable requise

Assurez-vous que votre certificat HTTPS est délivré et actif sur l'ensemble de vos sous-domaines (notamment www et APIs) avant d'activer preload.
