Absence d’en-tête HTTP Strict-Transport-Security (HSTS)

Votre serveur autorise encore les tentatives de dégradation de protocole (SSL Strip). Sans cet en-tête, les navigateurs ne forcent pas systématiquement le chiffrement TLS avant la première requête.

Temps estimé ~10 min
Difficulté Intermédiaire
1 Ajoutez l'en-tête de réponse dans votre fichier de configuration Netlify
netlify.toml
Configuration des en-têtes HTTP de sécurité 
[[headers]]
  for = "/*"
  [headers.values]
    Strict-Transport-Security = "max-age=63072000; includeSubDomains; preload"
    X-Content-Type-Options = "nosniff"
info

La valeur max-age=63072000 correspond à 2 années complètes. Le drapeau preload permet à votre domaine d'être inclus dans la liste interne de préchargement de Google Chrome, Mozilla Firefox et Apple Safari.
