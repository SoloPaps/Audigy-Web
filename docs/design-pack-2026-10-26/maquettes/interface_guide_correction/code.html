Guide de correction : Activer l'en-tête Strict-Transport-Security (HSTS)

L'en-tête HTTP Strict-Transport-Security ordonne impérativement aux navigateurs de communiquer exclusivement sous chiffrement HTTPS avec votre domaine, prévenant toute interception malveillante (man-in-the-middle) et toute attaque de dégradation SSL.

1

Localisez ou éditez votre fichier de configuration d'en-têtes HTTP

À la racine de votre projet ou dans le dossier de publication statique ( dist/ ou public/ ), créez ou ouvrez le fichier _headers .

2

Ajoutez la directive HSTS recommandée (2 ans + préchargement)

Insérez le bloc suivant pour verrouiller HTTPS pendant 2 ans (63072000 secondes), inclure tous les sous-domaines et autoriser l'inclusion dans la liste de préchargement des navigateurs (Chromium/Mozilla) :

public/_headers
1 /*
2 Strict-Transport-Security: max-age=63072000; includeSubDomains; preload

Validation préalable requise

Vérifiez que votre certificat SSL/HTTPS est bien valide et couvre l'ensemble de vos sous-domaines avant d'ajouter la mention preload . Un sous-domaine sans HTTPS valide deviendrait inaccessible.
