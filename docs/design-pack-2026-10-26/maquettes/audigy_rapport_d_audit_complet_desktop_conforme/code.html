## MISSION POUR L'ASSISTANT IA / LE DÉVELOPPEUR
Appliquez les corrections techniques ci-dessous selon les standards d'hygiène web Arc Soft.

### 1. [CRITIQUE · SÉCURITÉ] Activer l'en-tête HSTS
- Action : Fix direct
- Rôle cible : Hébergeur / CDN / Nginx
- Consigne : Ajouter l'en-tête `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload` dans la configuration du serveur web.

### 2. [IMPORTANT · PERFORMANCE] Compression AVIF des images hero
- Action : Fix direct
- Rôle cible : Développeur Web
- Consigne : Réencoder les bannières lourdes en AVIF/WebP avec balise <picture> et srcset responsif.

### 3. [MODÉRÉ · ACCESSIBILITÉ] Conformité RGAA 11.1 (aria-labels formulaires)
- Action : Vérification & Fix
- Rôle cible : Intégrateur Front-end
- Consigne : Lier chaque balise <label for="id"> aux <input> et <textarea> de la page contact.
