Pourquoi prouver le contrôle du domaine ?

Prouver que votre compte contrôle le domaine permet de débloquer : le détail complet du rapport, le brief IA de correction, le partage (public / équipe), et plus tard les tests actifs.

Balise meta HTML Rapide

Ajoutez cette balise meta dans la section <head> de la page d'accueil de votre site.

Code HTML à insérer dans <head> Prêt à copier 
<meta name="audigy-verification" content="audigy-verify=abc123exemple">
description

Fichier à la racine

Créez un fichier texte public contenant uniquement le jeton et déposez-le à la racine du domaine.

Chemin d'accès attendu :
https://exemple.fr/.well-known/audigy-verify.txt
Contenu strict du fichier :
audigy-verify=abc123exemple
dns

Enregistrement DNS TXT

Créez une entrée DNS de type TXT chez votre registrar ou hébergeur DNS.

Hôte / Nom :
@ ou _audigy
Type :
TXT
Valeur attendue :
audigy-verify=abc123exemple
schedule Note : la propagation DNS peut prendre quelques minutes selon votre fournisseur.
