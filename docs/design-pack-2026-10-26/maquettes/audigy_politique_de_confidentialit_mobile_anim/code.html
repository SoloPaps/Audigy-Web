Périmètre précis

Quelles données sont collectées

Nous appliquons le principe de minimisation stricte : aucune donnée comportementale, aucun fingerprinting d'appareil et aucune revente commerciale.

account_circle Compte utilisateur Requis

Adresse courriel unique, mot de passe haché par Argon2id (jamais stocké en clair), date d'adhésion aux Conditions Générales.

query_stats Preuves d'audit horodatées Fonctionnel

URL soumises, en-têtes HTTP publics analysés, métriques Web Vitals, empreintes WARC et instantanés visuels DOM générés par la sonde.

key Jeton Google Search Console Optionnel

Si connecté : jeton OAuth d'accès API chiffré symétriquement en AES-GCM 256 avec rotation de clef. Utilisé uniquement pour l'import de vos pages indexées.

terminal Journal d'accès technique (Logs) Sécurité

Adresse IP anonymisée (tronquage des deux derniers octets), User-Agent navigateur et code réponse HTTP pour la détection des attaques par déni de service.

3
Finalités & Cadre

Pourquoi nous les traitons

Chaque point d'interaction repose sur une base juridique claire et vérifiable au titre de l'Article 6 du RGPD :

gavel Base 1 • Exécution du contrat de service (Art. 6.1.b)
  • Génération et archivage des rapports de diagnostic santé.
  • Envoi des notifications d'anomalies critiques configurées.
  • Génération des fichiers d'exportation de conformité (JSON / PDF).
security Base 2 • Intérêt légitime de sécurité (Art. 6.1.f)
  • Prévention des abus de quota et protection contre le brute-force.
  • Protection anti-DDoS de l'infrastructure de scan.
  • Contrôle de l'intégrité cryptographique des certificats délivrés.
