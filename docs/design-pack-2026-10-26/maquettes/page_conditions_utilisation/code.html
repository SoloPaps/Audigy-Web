Principe éthique

Ce document est rédigé dans un français direct, sans tournure trompeuse ni clauses cachées, conçu pour garantir une sécurité technique et juridique mutuelle.

1

Service gratuit

Accès public

Audigy est gratuit. Il aide à comprendre l'état d'un site. Le service peut changer, ou s'arrêter, sans préavis.

Aucune souscription masquée, utilisation libre pour tous les éditeurs web.
2

Propriété et mandat

Obligation formelle

Vous déclarez être propriétaire du site, ou mandaté par écrit. Cette déclaration vaut avant tout test actif. Un test actif sans autorisation peut être une infraction. Le texte visé est l'article 323-1 du code pénal. Un test passif se limite à ce qu'un visiteur peut voir.

Référence Légale · Art. 323-1 Code Pénal

« L'accès frauduleux ou le maintien dans un système de traitement automatisé de données engage la responsabilité pénale individuelle de l'opérateur du test. »
