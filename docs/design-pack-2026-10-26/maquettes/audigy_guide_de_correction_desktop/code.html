Guide de correction : Activer l'en-tête HSTS

L'en-tête Strict-Transport-Security contraint les navigateurs à communiquer exclusivement en HTTPS avec votre domaine, prévenant toute interception man-in-the-middle et attaque de dégradation SSL.

Environnement de déploiement :
1
Localisez ou créez votre fichier d'en-têtes HTTP

À la racine de votre dépôt Git, ouvrez le fichier de configuration de vos en-têtes (netlify.toml, _headers ou vercel.json).

2
Ajoutez la directive HSTS standardisée

Insérez le bloc suivant pour verrouiller HTTPS pendant 2 ans (63072000 secondes), inclure tous les sous-domaines et permettre le préchargement HSTS (liste Chromium) :

netlify.toml / _headers
1 2 3 
/*
  Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
