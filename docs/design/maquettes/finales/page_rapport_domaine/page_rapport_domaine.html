Constats et actions recommandées

Filtrer les constats

  1. CritiqueImpact ≈ 1,1 s

    Images trop volumineuses à l’ouverture

    Des photos haute définition se chargent en pleine taille, même sur smartphone.

    Instruction pour le prompt IA : Images trop volumineuses à l’ouverture
    Corriger : Images trop volumineuses à l’ouverture

    Actions recommandées

    • Convertir les 6 visuels vers un format moderne (WebP ou AVIF).
    • Définir des dimensions maximales adaptées aux affichages mobiles.

    Fichiers cibles : hero-banner-atelier.jpg, fondateur-portrait.png

  2. CritiqueImpact ≈ 0,7 s

    Scripts qui s’exécutent trop tôt

    Le navigateur bloque l’affichage tant que des widgets annexes n’ont pas fini de tourner.

    Instruction pour le prompt IA : Scripts qui s’exécutent trop tôt
    Fiche détaillée à venir

    Actions recommandées

    • Ajouter l’attribut de report d’exécution (defer ou async) sur les scripts d’avis et d’analyse.
    • Différer le chargement des balises marketing après le premier rendu visuel.

    Fichiers cibles : widget-reviews.js, analytics-tag.js

  3. ModéréImpact ≈ 0,3 s

    Trop de styles d’écriture téléchargés

    4 familles de polices sont appelées, avec 8 variantes d’épaisseur superflues.

    Instruction pour le prompt IA : Trop de styles d’écriture téléchargés
    Fiche détaillée à venir

    Actions recommandées

    • Limiter la charte à 2 polices web et supprimer les graisses non utilisées.
    • Activer font-display: swap pour rendre le texte lisible immédiatement.

    Ressource : Google Fonts / WOFF2

  4. ConformeOptimal

    Compression des fichiers de code activée (Gzip / Brotli)

    Les pages HTML et les feuilles de style sont compactées avant l’envoi.

    Observation

    • Le serveur applique Brotli avec un ratio de compression supérieur à 70 % sur les ressources statiques.

    Statut : Protocole HTTP/2 actif

  5. ConformeOptimal

    Mise en cache du navigateur configurée

    Les éléments fixes ne sont pas re-téléchargés à chaque nouvelle page visitée.

    Observation

    • En-têtes Cache-Control réglés à 1 an pour les images et bibliothèques permanentes.

    Statut : Validé
