Résolution

Plan d’action en 3 étapes

Choisissez la version qui vous correspond : sans code via votre CMS, ou technique si vous gérez le site vous-même.

  1. 1

    Étape 1 : Convertir en WebP / AVIF

    Installez un plugin d’optimisation (Imagify, ShortPixel ou Smush). Il convertit vos fichiers existants sans réimport manuel.

    Gain moyen : −85 %

  2. 2

    Étape 2 : Redimensionner à la taille d’affichage

    La bannière fait 4000 px de large : réduisez-la à 1920 px maximum avant de l’envoyer dans votre bibliothèque de médias.

    Évite le surcoût mobile

  3. 3

    Étape 3 : Activer le chargement différé

    Vérifiez que le « lazy-loading » est actif sur les 5 images sous la ligne de flottaison : seuls le titre et le logo doivent charger en priorité.

    Améliore le LCP et le TBT

  1. 1

    Étape 1 : Convertir en WebP / AVIF

    Générez .avif et .webp avec Sharp (Node.js) ou cwebp en qualité 80, puis servez-les via la balise <picture>.

    Gain moyen : −85 %

  2. 2

    Étape 2 : Redimensionner avec srcset

    Produisez 3 paliers : 640w, 1024w et 1920w, et renseignez l’attribut sizes en cohérence avec vos media queries CSS.

    Évite le surcoût mobile

  3. 3

    Étape 3 : Prioriser et différer

    fetchpriority="high" sur la 1re image (LCP), loading="lazy" et decoding="async" sur les 5 autres.

    Améliore le LCP et le TBT

index.html · balise <picture>
<class="t">picture>
  <class="t">source type="image/avif"
    srcset="hero-640.avif 640w, hero-1024.avif 1024w, hero-1920.avif 1920w"
    sizes="100vw">
  <class="t">source type="image/webp"
    srcset="hero-640.webp 640w, hero-1024.webp 1024w, hero-1920.webp 1920w"
    sizes="100vw">
  <class="t">img src="hero-1024.jpg" width="1920" height="1248"
    alt="Atelier de menuiserie sur mesure"
    fetchpriority="high" decoding="async">
</class="t">picture>
