Choisissez une méthode de vérification

Publiez votre jeton

Une seule méthode est active à la fois. Les quatre utilisent le même jeton.

Votre jetonaudixio-verify=abc123exemple

Balise meta HTML Méthode sélectionnée

Ajoutez cette balise meta dans la section <head> de la page d’accueil de votre site.

Code HTML à insérer dans <head>Prêt à copier
<meta name="audixio-verification" content="audixio-verify=abc123exemple">

Fichier à la racine

Créez un fichier texte public contenant uniquement le jeton et déposez-le à la racine du domaine.

Chemin attendu
https://exemple.fr/.well-known/audixio-verify.txt
Contenu strict
audixio-verify=abc123exemple

Enregistrement DNS TXT

Créez une entrée DNS de type TXT chez votre registrar ou votre hébergeur DNS.

Hôte / Nom
@ ou _audixio
Type
TXT
Valeur attendue
audixio-verify=abc123exemple

⏱La propagation DNS peut prendre quelques minutes selon votre fournisseur.

Google Search Console Recommandé si GSC déjà configuré

Audixio confirme que votre compte Google possède ce domaine dans Search Console. Aucune modification de code ni de DNS. Connexion en lecture seule.
