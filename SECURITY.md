# Politique de sécurité

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilise le signalement privé de GitHub :
**Security → Report a vulnerability**
(https://github.com/SoloPaps/Audigy-Web/security/advisories/new).

Ton message reste visible uniquement par les mainteneurs jusqu'à la publication d'un correctif.

## Ce qu'il est utile d'indiquer

- la page, la fonction ou le fichier concerné ;
- les étapes pour reproduire le problème ;
- l'impact que tu estimes (données exposées, accès non autorisé, etc.) ;
- si possible, une piste de correction.

## Ce que tu peux attendre

Le projet est maintenu par une seule personne : les délais de réponse ne sont pas garantis. Je ferai au mieux pour accuser réception, évaluer la gravité et publier un correctif avant toute divulgation publique. Merci de laisser un délai raisonnable avant de rendre le problème public.

## Périmètre

Ce dépôt contient le code d'Audigy (site, fonctions, moteur d'audit, schéma de base). Les services tiers (Supabase, Netlify, Google) ont leurs propres politiques de signalement.

Merci de ne pas tester sur des données ou des sites qui ne t'appartiennent pas.
