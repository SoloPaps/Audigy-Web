## netlify
1. Ouvrez le fichier HTML de la page.
2. Placez un seul titre, d’environ 15 à 60 caractères.

```
<title>Cabinet d’ostéopathie à Lyon</title>
```

3. Décrivez cette page, pas seulement le nom du site.
4. Publiez à nouveau, puis relancez l’audit.

## github_pages
1. Écrivez un seul titre dans le fichier HTML du dépôt.
2. Limite : aucune sur le titre, le fichier HTML se modifie dans le dépôt.
3. Alternative : gardez le titre dans la page, pas dans un en-tête HTTP.

## generic
1. Placez un seul titre dans l’en-tête de la page.
2. Visez 15 à 60 caractères qui décrivent cette page.
3. Relancez l’audit après la mise en ligne.
