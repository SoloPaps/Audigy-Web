## netlify
1. Ouvrez la page et relevez les écarts cités.
2. Corrigez le texte, le nom ou le contraste indiqué.
3. Relancez l’audit. Ce n’est pas un audit RGAA complet.

## github_pages
1. Corrigez le HTML du dépôt pour les écarts cités.
2. Limite : cet outil ne couvre pas tout le RGAA.
3. Alternative : faites relire la page par une personne concernée.

## generic
1. Corrigez les écarts automatiques cités.
2. Relancez l’audit après la mise en ligne.
