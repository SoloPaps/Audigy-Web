---
title: Donner un titre à la page d'accueil
why: Le titre s'affiche dans l'onglet et dans les résultats de recherche.
effortMinutes: 5
sources:
  - MDN | https://developer.mozilla.org/fr/docs/Web/HTML/Element/title
---
## netlify
1. Ouvrez `index.html`.
2. Ajoutez dans `<head>` :

```html
<title>Nom de votre site</title>
```

## github_pages
1. Ouvrez `index.html` dans le dépôt.
2. Ajoutez la balise `<title>` dans `<head>`.

## generic
1. Ajoutez une balise `<title>` dans `<head>` de chaque page.
