## netlify
1. Supprimez le fichier du dossier publié.
2. Republiez le site.

## github_pages
GitHub Pages publie tout le dossier : la seule solution est de retirer le fichier du dépôt.

1. Supprimez le fichier du dépôt.

## generic
1. Supprimez le fichier du serveur ou bloquez son accès.
